One invented English word, defined in a single clear line of at most
140 characters.

## Run

```sh
node main.ts
```

Writes the word and its one-line definition to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output/entry.txt`),
after self-validating the gate: exactly one line, 1–140 characters,
no trailing newline.
